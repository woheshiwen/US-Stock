## 必读仓库文件（先 Read，再写作）
- templates/REPORT_SPEC_zh.md
- templates/STYLE_REFERENCE_zh.md

## 输出
- 路径：reports/YYYY-MM-DD.md（YYYY-MM-DD = 该美股交易日，美东收盘日）
- 若该文件已存在：用当日最新数据更新覆盖
- 不要改无关代码；不要开 PR（直接 commit 到 main）

## 数据与引用（与 Cursor 手动版相同）
1. 使用最新可获得数据，文末注明数据截至时间（美东收盘日 + 生成时间北京时间）。
2. 优先检索并引用：CNBC、Reuters、Bloomberg、MarketWatch、WSJ、Yahoo Finance、Investing、FRED、CME FedWatch、密歇根大学消费者调查、Cboe、公司 IR 等；关键事实带链接。
3. 不得编造；无可靠数据写「暂无可靠数据」。
4. 判断区分：已发生事实 / 数据推断 / 主观判断 / 需继续观察。
5. 不构成投资建议；操作倾向仅用「观察」「风险控制」。

严格按 REPORT_SPEC 完整输出第 0–15 节（含全部表格列名），不得省略章节，不得用简表代替长文。
