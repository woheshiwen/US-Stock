# Astra 问卷 · 管理员回收说明（内部）

## 1. 认知题参考（用于统计“是否读懂”，非考核打压）

**C1 正确倾向：** 「先把设计意图写清楚，再让 AI 高效执行…」

**D1 擅长（应选）：**  
代码驱动 Blender；自然语言体块/场景；参数化脚本；按模板生成 PPT/文档/表格。  
**不应作为“擅长”勾选：** 场地文脉最终判断；植物生态最终科学裁定。

**D2 不能替代（应多选齐）：**  
文脉/场所精神；植物生态；规范与构造安全；最终审美；交付前负责人签字。

## 2. 汇总时可做的三张表

1. **岗位 × 场景切入**（E1）：看试点优先落在方案/植物/施工图/商务哪条链  
2. **报名意愿**（G1）与 **支持需求 Top5**（G3）  
3. **顾虑词云**（F2）：保密、尺度、同质化、额度等，决定培训与制度优先序

## 3. 与老板材料的对应关系

| 问卷板块 | 对应材料要点 |
|----------|----------------|
| C | Think First 80/20；情感与叙事弯道 |
| D | 能力边界与审核红线 |
| E | 六场景指南 + 岗位映射 |
| F–G | 落实要求中的反馈题与试点选拔 |
| H | 额外收集落地卡点（原材料未覆盖） |

## 4. 建议试点选拔权重（示例）

- 主动报名 + 有真实项目可绑：高  
- 已读材料且 C/D 认知到位：高  
- 仅观望或未读材料：暂缓  
- 商务/项目经理：可优先试「场景6 标书/汇报」形成快速可见成果
