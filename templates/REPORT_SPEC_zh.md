# 美股收盘日报生成规范（必须与 Cursor 手动版一致）

## 输出标题
`# 美股收盘日报｜YYYY-MM-DD`

## 必须包含的章节（0–15，标题与顺序不可省略）

0. 今日一句话总结（3–5句 +「今日市场状态：」一句）
1. 大盘表现总览（完整表格：指数/收盘/涨跌幅/日内高低/成交量变化/技术状态）
2. 盘中走势复盘（时间线：盘前/开盘/午盘/尾盘/盘后；核心原因；sell the news 等标签）
3. 宏观环境
   - 3.1 美债收益率（2Y/10Y/30Y、利差、分析）
   - 3.2 Fed 降息预期（CME FedWatch、年内降息次数、变化、官员讲话）
   - 3.3 美元/黄金/原油/加密货币（表格+解读）
   - 3.4 当日重要经济数据（表格：数据/实际/预期/前值/解读）
4. 板块表现（11 板块：排名/板块/ETF/当日/近5日/近1月/相对标普/驱动）
5. 主题与风格表现（半导体/软件/网络安全/云计算/AI/光通信/数据中心/核电/储能/大小盘/等权等）
6. 市场宽度与参与度
   - 6.1 均线参与度（多指数 × 20/50/100/200 日线比例）
   - 6.2 涨跌家数、新高新低（NYSE/Nasdaq）
   - 6.3 其他内部指标（A/D、McClellan、Put/Call、VIX 期限结构等，能写则写）
7. 技术面分析（SPY/QQQ/IWM/SMH/IGV/XLK/XLC/XLY 等表格）
8. 重点个股
   - 8.1 七巨头
   - 8.2 AI 硬件/半导体（覆盖清单内股票）
   - 8.3 软件/SaaS
   - 8.4 AI 电力/数据中心
   - 8.5 其他显著异动
9. 财报日历（9.1 昨夜财报；9.2 未来 1–3 日）
10. 机构观点与资金流
11. 板块轮动判断（从给定状态列表中选择并说明）
12. 重点关注股观察（固定股票池 + 标签：继续强势/高位震荡/短线过热/回踩支撑/破位风险/等财报催化/利好兑现/低位修复/需要观察）
13. 明日交易计划/观察清单（13.1–13.4）
14. 风险提示（风险维度表格 + 等级 低/中/中高/高）
15. 最终结论（今日市场结论、当前市场阶段、操作倾向、明天 5 个信号）

## 数据与引用（硬性）
1. 使用 DATA_JSON 与 WEB_CONTEXT 中的最新数据，注明截至时间。
2. 优先引用 DATA_JSON.sources 中的权威来源（CNBC、Reuters、Bloomberg、MarketWatch、WSJ、Yahoo、Investing、FRED、CME、密歇根大学、公司 IR 等）。
3. 关键事实必须带链接或来源名。
4. 不得编造；无数据写「暂无可靠数据」。
5. 冲突时说明差异并采用更权威、更实时来源。
6. 市场判断区分：已发生事实 / 数据推断 / 主观判断 / 需继续观察。
7. 不构成投资建议；操作倾向仅「观察」「风险控制」。

## 排版
- 使用 Markdown 表格，与用户模板列名一致。
- 章节用 `---` 分隔。
- 与 Cursor 手动版层级、表头中文一致。
